# موقع شركة الهنا اليكتريك

الموقع المنشور: **https://elhana.pages.dev**

صفحة واحدة ثابتة — لا قاعدة بيانات ولا خادم ولا عملية بناء. الملف
`index.html` هو الموقع كله، ومجلد `img` هو صوره. من يرفع ملفًا هنا
يكون قد غيّر الموقع؛ لا خطوة أخرى.

---

## بنية المستودع

```
index.html          الموقع كله: النص والتنسيق والسكربت في ملف واحد
img/                كل الصور والشعار
README.md           هذا الملف — الرفع والنشر
دليل-التعديل.md      كيف تغيّر النصوص والصور والأسعار
robots.txt          يسمح لمحركات البحث بالفهرسة
sitemap.xml         خريطة الموقع لمحركات البحث
```

## الرفع من المتصفح

أسهل طريق، وتعمل من الهاتف:

1. افتح المستودع على GitHub
2. ادخل المجلد الذي ستضع فيه الملف (`img` للصور، أو ابقَ في الجذر لـ`index.html`)
3. **Add file › Upload files**
4. اسحب الملفات أو اخترها
5. اكتب في **Commit changes** سطرًا يصف ما فعلت — "إضافة صور المصنع" لا "update"
6. **Commit changes**

الملف المرفوع باسم موجود **يستبدله**. وهذا مقصود: لتغيير صورة، ارفع
صورة جديدة بنفس الاسم القديم بالضبط.

---

## النشر

Cloudflare Pages مربوطة بالمستودع وتنشر تلقائيًا بعد كل commit.
التحديث يظهر خلال دقيقة إلى دقيقتين.

لم يظهر التغيير؟ بالترتيب:

1. **انتظر دقيقتين** — النشر لم ينتهِ بعد
2. **حدّث الصفحة تحديثًا قسريًا** — المتصفح يحتفظ بنسخة قديمة
3. **افتحها في تبويب خفي** — يتجاوز الكاش تمامًا، فيقطع الشك
4. راجع **Deployments** في لوحة Cloudflare: هل النشر نجح أم فشل؟

## قبل أي تعديل على `index.html`

اقرأ **`دليل-التعديل.md`** — فيه كل ما يمكن تغييره وكيف.

وداخل `index.html` نفسه، كل موضع قابل للتعديل عليه علامة **✏️** ومكتوب
فوقه ماذا يفعل. ابحث في الملف عن `✏️` لترى المواضع كلها.

**قاعدة واحدة تحمي الموقع:** غيّر **النص بين الوسمين** فقط، ولا تلمس
الوسوم نفسها ولا ما بين `<style>` و`</style>`. النص الذي يظهر للزائر
يقع دائمًا بين `>` و`<`:

```html
<h2><span data-ar>المصنع</span><span data-en-only>Our facility</span></h2>
             ▲ غيّر هذا                    ▲ وهذا (الإنجليزية)
```

الموقع بلغتين: `data-ar` للعربية و`data-en-only` للإنجليزية. **غيّر
الاثنين معًا** وإلا ظهر نصٌّ قديم لمن يبدّل اللغة.

## الرجوع خطوة إلى الوراء

أفسدتَ شيئًا؟ لا شيء ضاع — GitHub يحتفظ بكل نسخة:

1. افتح الملف على GitHub
2. اضغط **History**
3. اختر آخر نسخة كانت سليمة
4. **⋯ › Revert** أو انسخ محتواها وارفعه من جديد

لهذا السبب تحديدًا يُكتب في `Commit changes` وصفٌ مفهوم: بعد شهرين
ستبحث في القائمة عن النسخة التي تريدها.

## ما لا يُرفع هنا إطلاقًا

- كلمات مرور أو مفاتيح أو أي بيانات دخول — المستودع عام، ومن يفتحه يقرأها
- عروض أسعار أو رسومات عملاء أو أي مستند خاص بمشروع
- صور فيها وجوه عاملين بلا إذنهم
